# 架构规范（Go）
版本 0.2 · 2026年9月18日

- **单一职责**：文件/类型/函数只做一件事；单文件原则上 ≤ 300 行，超出须标注理由
- **分层单向**：表现层 (API/CLI) → 业务层 (Service) → 数据层 (Repository/DAO)，禁止跨层（如表现层直接操作数据库）；禁止循环依赖
- **契约**：模块间通信基于 interface 而非具体实现；接口由消费方定义（accept interfaces, return structs）
- **无状态**：核心服务/函数输入确定则输出确定；必须存状态时集中到存储层
- **配置外置**：数据库连接、API 密钥、超时时间等一律由环境变量或配置文件注入，禁止硬编码

自检后以 [WARN] 标注违反项。
