# 测试规范（Go）
版本 0.13 · 2026年9月18日

- **同行**：每个新增业务函数同时产出同包 *_test.go；核心逻辑覆盖率 ≥ 80%（go test -coverprofile）；含 if/else 或 if err != nil 分支的函数必须有测试
- **隔离**：外部 API、数据库、网络、文件系统一律用基于 interface 的 fake/mock，单元测试禁止真实调用线上付费接口
- **集成**：有依赖关系则做交叉集成；两级以上依赖必做全链路集成
- **独立**：用例可单独运行，执行顺序不影响结果（禁止 A 依赖 B 预置数据）
- **AAA**：Arrange → Act → Assert 三段以空行分隔；表驱动测试每个 case 内部同样遵守
- **边界**：覆盖正常流、边界值（空值/最大最小）、错误流（if err != nil）
- **并发**：并发用例必须跑 go test -race；禁止 time.Sleep 做同步，改用 channel/WaitGroup
- **一键运行**：单条命令 go test ./... 完成并输出通过率报告

自检后以 [WARN] 标注违反项。
