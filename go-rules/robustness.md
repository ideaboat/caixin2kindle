# 代码健壮性审查规范（Go）
版本 1.1 · 2026年9月18日

健壮性 = 功能之外，抵抗异常、防御错误、自我恢复的能力。错误处理粒度见《编码规范》，验收见《测试规范》。

- **安全边界**：外部输入必校验（注入/越权/溢出），nil、边界值、并发冲突全覆盖
- **错误回滚**：IO/网络/三方调用/序列化等失败路径须有捕获、降级或回退；复合变更加原子回滚；可预见业务失败用返回 error 而非 panic；禁止静默吞错误
- **资源并发**：资源紧跟打开处 defer 释放；禁止无上限消费、循环内查库（N+1）、无限期挂起 IO；goroutine 必须有退出条件；共享可变状态用 mutex/channel 保护；跨层传递 context.Context 且外部调用设超时，禁止在库内新建 Background context
- **可观测幂等**：关键路径记入参/错误/耗时日志并脱敏；关键写接口幂等
- **架构解耦**：模块松耦合，单点故障不扩散；多锁须规定加锁顺序或用超时锁

红线：
- ❌ 静默吞错误（`_ =` 丢弃、空 `if err != nil {}`）
- ❌ 对外暴露内部信息（堆栈/路径/版本）
- ❌ 日志明文打印密码、密钥
- ❌ 并发改动未通过 `go test -race`

自检后以 [WARN] 标注违反项。
