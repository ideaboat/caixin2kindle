# 编码规范（Go）
版本 0.2 · 2026年9月18日

- **命名**：用完整英文单词表达意图，禁用单字母（循环变量除外）与模糊缩写（data/info/process）；导出 MixedCaps 首字母大写、未导出小写、不用下划线（TestXxx_Yyy 除外）；缩写全大写（ID/URL/HTTP）；取值方法用 Name() 不用 GetName()；包名小写单数且不与导出名重复
- **文档**：导出标识符必须有以自身名开头的 GoDoc 注释（用途/入参/返回值）；复杂算法加步骤注释
- **错误**：error 是最后一个返回值且必须处理，禁止 `_ =` 丢弃（确需忽略须写理由）；用 %w 包装、errors.Is/As 判断，禁止字符串比较错误；panic 仅限不可恢复的编程错误；recover 仅限 goroutine 边界或中间件
- **函数**：≤ 50 行（含空行），嵌套 ≤ 4 层，优先 early return
- **类型**：依赖编译期类型检查，禁止用 any/interface{} 逃避类型
- **门禁**：gofmt、go vet 必须通过

自检后以 [WARN] 标注违反项。
